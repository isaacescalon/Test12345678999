## What is Spur?
Spur is a practice tool for writing prompts. It runs in your web browser from a single file, so there is nothing to install. You pick a field (including Accounting and Finance), choose a scenario, write a prompt, and get feedback against a rubric. It also tracks points (XP), levels, and a leaderboard.

Use it alongside the pattern from the Prompting & Context page: **Goal + Context + Constraints + Output + Check**. Write your prompt, then ask yourself whether each of the five parts is there before you submit.

## How to save it on your computer
1. **Download the file.** Right-click the link above and choose **Save link as...** (Chrome, Edge, Firefox) or **Download Linked File As...** (Safari).
2. **Keep the name and the ending.** Save it as `Spur.html`. Make sure it does not end in `.txt`.
3. **Choose a place you will remember,** such as your Downloads or Desktop folder.
4. **Open it.** Double-click `Spur.html`. It opens in your default web browser.
5. **Start practicing.** Pick a display name and a badge. No password is needed.

**Viewing it on GitHub?** Open the `Spur.html` file in the repository and click the **Download raw file** button (the download icon at the top right of the file view). Then follow steps 2 to 5.

## Good to know
- **Your progress is saved in your browser** on that computer. Using a different browser or computer starts fresh.
- **The AI grader is optional.** The file includes an option to add your own Anthropic API key for AI-based grading. The key stays in your browser and is sent only to Anthropic. Each graded prompt uses your own API credits, so skip this unless you want it.
- **Use a nickname.** Do not use your email as a display name.
- **Do not put private information in a practice prompt.** Use made-up numbers and names, just like the examples in this repository.
- **The leaderboard needs a connection.** It only shows other players if the file is connected to a shared service. If not, you will see only your own progress.

## Try it yourself
1. Open Spur and choose Accounting or Finance, or the field closest to your major.
2. Write a first prompt without looking at the pattern. Check your feedback.
3. Rewrite it using Goal + Context + Constraints + Output + Check. Did your score improve?
4. Compare your final prompt to the "After" example on your field's page in this folder.
